# 🚀 Git na Prática: Do Zero ao Pull Request

Bem-vindo ao repositório interativo da nossa apresentação! Aqui você não é apenas um espectador, você é um colaborador. Vamos colocar a mão na massa e praticar o fluxo real de trabalho com Git e GitHub.

## 📋 Pré-requisitos

Antes de começarmos, certifique-se de que você tem:

- Uma conta no [GitHub](https://github.com/).
- O [Git](https://git-scm.com/) instalado na sua máquina.
- Um editor de código da sua preferência (VS Code, por exemplo).

---

## 🛠️ O Desafio: Deixe sua marca!

Seu objetivo é adicionar o seu nome e sua linguagem/tecnologia favorita ao arquivo `participantes.md` e abrir um Pull Request (PR) para integrarmos ao vivo na branch principal (`main`).

Siga o passo a passo abaixo junto com a apresentação:

### Passo 1: Clonar o Repositório (O Motor)

Abra o seu terminal e traga o código para a sua máquina:

```bash
git clone [https://github.com/RBastos93/GIT-SEPE.git](https://github.com/RBastos93/GIT-SEPE.git)
cd GIT-SEPE
```
